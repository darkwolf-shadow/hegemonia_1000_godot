# Hegemonia 1000

Versione in Godot 4 dello strategico storico ambientato nell'anno 1000.

## Come aprire il progetto

1. Scarica e installa [Godot 4.3](https://godotengine.org/) o superiore.
2. Avvia Godot e clicca "Importa".
3. Seleziona la cartella `hegemonia_1000_godot`.
4. Clicca "Modifica" per aprire il progetto.
5. Premi F5 per avviare il gioco.

## Struttura del progetto

- `project.godot` - configurazione del motore
- `data/` - tutti i dati del gioco in formato JSON
- `scripts/` - codice del gioco
- `scenes/` - schermate e mappe
- `assets/` - immagini, icone, temi grafici

## Stato attuale

Il progetto contiene la struttura base:
- autoload per stato, dati, economia, intelligenza artificiale, battaglie e salvataggi;
- dati di esempio per fazioni, province, truppe, navi, edifici e terreni;
- mappa GeoJSON di esempio;
- menu principale, mappa strategica e schermata delle battaglie.

I dati completi storici verranno inseriti nei file JSON in `data/`.
