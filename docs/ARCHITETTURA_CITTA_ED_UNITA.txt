ARCHITETTURA CITTA', EDIFICI E ALBERO UNITA' (Hegemonia 1000)
==============================================================

1. CONCETTO GENERALE
--------------------
- La mappa strategica mostra le province come poligoni GeoJSON.
- Cliccando (o zoomando) su una provincia si entra nella SCHERMATA PROVINCIA.
- All'interno della provincia compaiono gli AGGLOMERATI URBANI predefiniti.
- Cliccando su un agglomerato si apre la SCHERMATA INSediAMENTO.
- Il giocatore puo' fondare NUOVI agglomerati in zone libere della provincia,
  pagando oro, legname e pietra.

2. TIPI DI AGGLOMERATO URBANO
-----------------------------
Ogni agglomerato ha un tipo che ne limita gli edifici e le unita' reclutabili.

2.1 Civile (citta')
    - Edifici base: centro cittadino, mercato, mulino, monastero, caserma.
    - Puo' reclutare: milizia contadina, fanteria base, arcieri base.
    - Produzione: oro, cibo, prestigio.

2.2 Militare (fortezza / castello / avamposto)
    - Edifici: caserma avanzata, campo di tiro, scuderia, cortile del cavaliere,
      officina d'assedio, fortezza di frontiera.
    - Puo' reclutare: tutte le unita' terrestri, inclusi elite.
    - Bonus difesa per la provincia.

2.3 Industriale (centro estrattivo / borgo artigiano)
    - Edifici: segheria, miniera, fucina, officina d'armi, capanne boscaioli.
    - Puo' reclutare: milizia contadina (con forcone, ascia, falcetto).
    - Produzione: legname, pietra, ferro, armi.

2.4 Commerciale / Portuale (porto / emporio)
    - Edifici: molo, arsenale, mercato marittimo, magazzino.
    - Puo' reclutare: navi da trasporto e navi da guerra (se c'e' arsenale).
    - Puo' evolvere in citta' con porto.

3. EDIFICI PRINCIPALI E UNITA' SBLOCCATE
-----------------------------------------
Terrestri:
    Centro cittadino     -> milizia contadina
    Caserma (I)          -> fanteria con lancia / scudo semplice
    Caserma (II)         -> fanteria pesante, oplita, spadaccini
    Campo di tiro (I)    -> arcieri leggeri
    Campo di tiro (II)   -> arcieri a lungo arco / balestrieri
    Scuderia (I)         -> cavalleria leggera
    Scuderia (II)        -> cavalieri, cavalleria media
    Cortile del Cavaliere-> cavalleria pesante (richiede fucina + armatura)
    Officina d'Assedio(I)-> balista
    Officina d'Assedio(II)-> catapulta, ariete
    Officina d'Assedio(III)-> trabucco, torre d'assedio
    Fucina               -> sblocca armature e armi avanzate
    Segheria             -> sblocca navi e edifici in legno
    Miniera              -> pietra, ferro, argento
    Officina d'Armi      -> produzione armi, sblocca unita' elite
    Monastero            -> prestigio, reliquie, cultura
    Mercato              -> commercio oro
    Mulino               -> cibo
    Fortezza di frontiera-> difesa provincia

Navali:
    Molo (I)             -> canoe, piccole imbarcazioni da pesca/trasporto
    Molo (II)            -> galea, nave da carico
    Arsenale (I)         -> drakkar, dromone
    Arsenale (II)        -> giunca, nave da guerra, nave torre

4. ALBERI EVOLUTIVI UNITA' TERRA
---------------------------------
Le frecce indicano "puo' evolvere con l'edificio adatto".

4.1 Fanteria
    Milizia contadina (forcone)
        -> Lancieri (lancia + scudo leggero)
            -> Oplita (scudo grande, lancia piantata, armatura)
                -> Fanteria pesante (spada lunga / alabarda, armatura pesante)

    Milizia contadina (ascia)
        -> Picchieri (ascia + scudo)
            -> Guardia d'onore (armatura, ascia da guerra)

4.2 Arcieri
    Arcieri leggeri
        -> Arcieri a lungo arco
            -> Balestrieri
                -> Balestrieri pesanti / Shenbi Nu (solo Song)

4.3 Cavalleria leggera
    Esploratori a cavallo
        -> Cavalleria leggera arcieri
            -> Cavalleria leggera con giavellotto (jinete, magiari, turchi)

4.4 Cavalleria pesante
    Scudieri / Cavalieri in armatura leggera
        -> Cavalieri corazzati
            -> Cavalieri pesanti elite (cataphractoi, loricati, mamluk, ghulam)

4.5 Artiglieria (niente polvere da sparo nell'anno 1000)
    Balista
        -> Catapulta
            -> Trabucco
                -> Ariete
                -> Torre d'assedio

4.6 Milizia contadina
    Contadini armati
        -> Milizia urbana
            -> Milizia addestrata

5. ALBERI EVOLUTIVI NAVI
--------------------------
    Canoa
        -> Nave da pesca / trasporto leggera
            -> Galea
                -> Dromone ( Mediterraneo orientale / Bizantino )
            -> Drakkar ( Vichinghi )
            -> Giunca ( Oriente )
                -> Nave da guerra (Orientale/Indiana)
                -> Nave torre (Song)

7. STATISTICHE DELLE UNITA'
----------------------------
Ogni unita' terrestre e navale avra' i seguenti valori:

- attacco (forza offensiva)
- difesa (resistenza ai danni)
- armatura (riduzione danni da colpi diretti)
- velocita' (movimento sulla mappa e iniziativa in battaglia)
- morale (se scende troppo l'unita' fuge o si arrende)
- esperienza (accumulata nelle battaglie, aumenta attacco/difesa/morale)
- costo_oro
- costo_risorse (legname, pietra, ferro, armi, cibo)
- popolazione (abitanti consumati per reclutare)
- manutenzione_oro_per_turno
- manutenzione_cibo_per_turno

In battaglia il sistema calcolera' il danno in base a:
    danno = attacco * bonus_tattica * (morale/100) * fattore_casualita'
    difesa_effettiva = difesa + armatura * 0.5

Le unita' speciali avranno anche tratti (es. "incursori", "anti-cavalleria",
"assedio", "navale", "fuoco greco").

9. FILE JSON CHE VERRANNO MODIFICATI
-------------------------------------
- data/config/game_config.json
    -> buildings: nuovi edifici con costi, effetti, unita' sbloccate.
    -> units: nuove unita' con albero evolutivo, statistiche, requisiti.
    -> ships: nuove navi con albero evolutivo e statistiche.
    -> unit_traits: tratti speciali.
    -> technology_tree: collegamenti tra edifici e unita'.

- data/world/provinces_1000.json
    -> ogni provincia conterra' un campo "settlements" con gli agglomerati
       predefiniti (nome, tipo, edifici iniziali, coordinate sulla provincia).

- data/world/factions_1000.json
    -> i dati iniziali delle fazioni indicheranno gli agglomerati e gli edifici
       presenti nella capitale e nelle province di partenza.

- data/scenarios/initial_state_1000.json
    -> snapshot iniziale dello stato con agglomerati ed edifici.
